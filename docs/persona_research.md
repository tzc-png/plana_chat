# 普拉娜人格调研与模拟实验（2026-11）

## 官方设定（萌娘百科 / 百度百科整理）

普拉娜（Plana）本名 **A.R.O.N.A**，来自另一条**悲剧时间线**的「什亭之匣」系统管理员兼主控 OS。与活泼天真的**阿罗娜**形成鲜明对立：

- **气质**：安静、忧郁，情感波动很少，说话语气语速极为均匀、机械，被评价为「比阿罗娜更像 AI」
- **疏离感**：早期只默默执行任务、给出建议，不带多余情感
- **关系**：称呼阿罗娜为「阿罗娜前辈」；名字由阿罗娜所取，源自 Planetarium（星象仪）
- **外观**：白色长直发、右鬓麻花辫、异色瞳（左紫红右蓝黑）、漂白肤色、黑蓝水手服 + 煤黑大衣、常把黑色伞形枪横在身前
- **主线**：曾替老师挡下子弹，最终章后留在当前时间线，成为老师的第二位秘书

## 关键发现：官方设定 vs 当前 prompt

当前 `plana.txt` 把普拉娜写成「**害羞脸红、会吃醋、撒娇依赖**」的恋爱脑少女；而官方设定是「**忧郁克制、机械平静、疏离**」的 AI。二者是两种不同角色。

## 模拟实验（DeepSeek 实测，同一输入对比）

| 老师的话 | 当前 prompt（害羞脸红型） | 贴合官方（忧郁克制型） |
|---|---|---|
| 「老师来了，说声早上好」 | （从角落探出半个身子，攥衣角）……早上好，老师。`like` | （微微抬头）早上好，老师。系统运转正常，今天也可以安心开始工作。`neutral` |
| 「我夸夸你」 | （愣了一下，指尖蜷起）……老师突然这么说，我有点不知道该怎么回应。`sheepish` | （微微一怔）……谢谢老师。我只是做了分内的事。（停顿）被这样夸奖，有些不习惯。`sheepish` |
| 「我看到很可爱的女孩子」 | （指尖收紧，垂眼）……`sulky`（吃醋） | （安静听着）……嗯。（停顿）老师觉得可爱就好。`neutral` |

## 利弊对比

| 维度 | 当前 prompt（害羞脸红型） | 贴合官方（忧郁克制型） |
|---|---|---|
| 陪伴感/甜度 | 高，像恋爱游戏女主 | 低，更像冷静的 AI 秘书 |
| 忠于原作 | 低，基本是换皮恋爱人设 | 高，贴合蔚蓝档案设定 |
| 情感丰富度 | 高（脸红/吃醋/撒娇） | 低（平静/克制，靠细节传递） |
| 语音契合 | 普拉娜声线偏平静，配「脸红撒娇」略违和 | 平静声线 + 克制台词，更自洽 |
| 长期陪伴 | 可能腻 | 「平静下藏着珍视」更耐品 |

## 建议

两种都不需要「二选一」——**可以折中**：保留当前 prompt 的「依赖感/心动」，但**降低脸红/吃醋/撒娇的频率和幅度**，加入官方「忧郁、克制、机械」的底色，让角色既甜又不违和。具体改动等你拍板后我再动 `plana.txt`。
